# Aman Dhaba

Authentic Indian Dhaba & Restaurant web experience.

## Overview
Aman Dhaba brings the complete visual rhythm, cinematic editorial layout, responsive design, and hospitality experience of traditional Indian dining to the web.

## Features
- **Cinematic Homepage**: Full-screen video hero, promotional bottomless brunch banner, feature slideshow carousel, about/catering editorial stories, interactive masonry photo gallery, customer reviews carousel, and location/contact info.
- **Dedicated Pages**: Food Menu with filtering, Drinks, Specials, Catering inquiry, Private Parties & Events booking, and Table Reservations.
- **Responsive & Accessible**: Fully optimized for mobile, tablet, and desktop viewports with WCAG AA compliance and reduced motion support.
- **Centralized Configuration**: All restaurant details, hours, contact, and menu items defined in `src/config/restaurant.ts`.

## Tech Stack
- React / TypeScript
- Vite
- Lucide Icons
- Vanilla CSS Design System

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Run tests
npm run test

# Typecheck and build for production
npm run build
```
